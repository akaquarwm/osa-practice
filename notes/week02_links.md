## 2교시 — 교수님 허용에 따른 개인 실습

- Issue: https://github.com/akaquarwm/osa-practice/issues/1
- PR: 원격 브랜치 업로드 후 생성 예정
- base: akaquarwm/osa-practice의 main
- compare: 같은 저장소의 feature/contributing
- Fork: 짝 저장소를 사용하지 않는 개인 실습이므로 생략
- 타인 리뷰 코멘트 URL: 해당 없음(상호 리뷰 생략)
- Request changes 및 Approve: 수행하지 않음. 타인 리뷰를 받은 것으로 기록하지 않음.
- 자체 점검: README 기여 방법, 브랜치 이름 예시, PR 하나의 변경 범위, 비밀정보 미포함을 확인함.
- 예상: PR에는 main을 기준으로 feature/contributing의 기여 방법 추가가 나타날 것이다. PR의 Closes #1이 기본 브랜치 병합 시 Issue 종료와 연결될 것이다.
- Fork는 다른 소유자의 저장소를 내 계정에서 수정할 공간을 만들고, branch는 한 저장소 안에서 작업 흐름을 분리한다.
